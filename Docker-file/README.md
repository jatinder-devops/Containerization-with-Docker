# 🐳 Dockerfile Learning from Scratch

Welcome to my Dockerfile learning repository!

This repository documents my hands-on journey of learning Dockerfiles from fundamental concepts to advanced containerization practices. It contains practical examples, explanations, commands, troubleshooting tips, and projects designed to build real-world DevOps skills.

## 🎯 Objectives

- Understand Dockerfiles and containerization fundamentals.
- Learn important Dockerfile instructions.
- Build and run custom Docker images.
- Understand image layers and build caching.
- Learn environment variables and build arguments.
- Implement multi-stage builds.
- Apply Dockerfile security and optimization practices.
- Use Docker Compose to manage containers.
- Build a practical Apache web server project.

## 📚 Learning Roadmap

| No. | Topic | Learning Goal |
|---|---|---|
| 01 | Introduction | Understand Dockerfiles |
| 02 | First Dockerfile | Build your first image |
| 03 | FROM | Select base images |
| 04 | RUN | Execute build-time commands |
| 05 | COPY and ADD | Manage application files |
| 06 | WORKDIR | Organize application directories |
| 07 | CMD and ENTRYPOINT | Configure container startup |
| 08 | ENV and ARG | Manage configuration |
| 09 | EXPOSE | Understand container ports |
| 10 | USER and LABEL | Improve security and metadata |
| 11 | .dockerignore | Exclude unnecessary files |
| 12 | Layers and Cache | Optimize image builds |
| 13 | Multi-Stage Builds | Reduce final image size |
| 14 | HEALTHCHECK and VOLUME | Understand health and persistence |
| 15 | Best Practices | Improve image security |

## 🛠️ Technologies

- Docker and Dockerfiles

- Docker Compose

## 💻 Learning Method

Each topic contains explanations, practical examples, commands, and exercises. All examples are intended to be tested in a suitable Docker environment.

Build a strong foundation in Docker, containerization, image optimization, and DevOps workflows through consistent hands-on practice.
